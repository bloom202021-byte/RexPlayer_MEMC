# REX Player v3.0.0 — GPU Video Player (MEMC & Secondary Sub-Frame Cascade FBO)

Видеоплеер с аппаратным ускорением WebGL для многопроходной интерполяции кадров (MEMC 60/90/120/144 FPS), вторичной каскадной генерации промежуточных суб-кадров (Secondary Sub-Frame Cascade FBO), GPU-апскейлинга до 4K UHD (GSR / FSR / Anime4K / Кино) и тональной компрессии HDR10.

## Возможности v3.0.0
- **Интерполяция кадров (MEMC) и Каскад суб-кадров (Secondary Sub-Frame Cascade FBO)**:
  - **Pass 1 (5-уровневая пирамида оптического потока)**: иерархический поиск векторов движения (`16×9 → 32×18 → 64×36 → 128×72 → 256×144`), Symmetric SAD, субпиксельное уточнение Лукаса-Канаде, медианная фильтрация и проверка прямой/обратной согласованности в GPU FBO.
  - **Pass 2A (Anchor Mid-Frame FBO `I_0.5`)**: синтез стабилизированного опорного промежуточного кадра ($\alpha = 0.50$) в выделенный FBO-буфер видеопамяти при поступлении каждой новой ключевой пары кадров.
  - **Pass 2B (Hierarchical Secondary Sub-Frame Synthesis)**: вторичная генерация промежуточных суб-кадров (**Авто / 2x / 3x / 4x**) между реальным кадром и опорным буфером $I_{0.5}$ с половинным радиусом смещения векторов ($0.5 \cdot \vec{V}$), контролем когерентности векторов и защитой быстрых сцен от двоения.
- **GPU Супер-разрешение (Super Resolution) и HDR10**:
  - 9-Tap направленный апскейлинг 1.5x / 2.0x / 4.0x 4K UHD (Snapdragon GSR, AMD FSR/CAS, Anime4K, Кино) с анти-рингингом и подавлением блочного шума (De-block).
  - Аппаратный тонмаппинг ACES Filmic / Rec.2020 и профиль Qualcomm Adreno (GMEM FP16 + True10 HDR).
- **Медиатека и управление**:
  - Автоматическая генерация превью-иконок (thumbnails) и метаданных при загрузке локальных видеофайлов с сохранением в IndexedDB Vault.
  - Поддержка локальных видеофайлов, папок смартфона, потоковых URL и внешних субтитров (`.srt`, `.vtt`).
  - 5-полосный аудиоэквалайзер с предусилителем на базе Web Audio API.
  - Интерактивный инспектор фазы суб-кадров ($\alpha = 0.00 / 0.25 / 0.50 / 0.75 / 1.00$), шторка сравнения «До / После», покадровый шаг и захват PNG из WebGL-буфера.

## Запуск локально

```bash
npm install
npm run dev
```
